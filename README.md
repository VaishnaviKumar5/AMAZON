# Amazon SQL Data Analysis Project
 
## Project Overview

This project focuses on analyzing Amazon retail data using MySQL to extract meaningful business insights.
 
## Tools Used

- MySQL

- MySQL Workbench
 
## SQL Concepts Used

- DDL and DML

- SQL Constraints

- Primary Key and Foreign Key

- Joins

- Aggregate Functions

- GROUP BY and HAVING

- Subqueries

- Window Functions

- CASE Statements

- Database Normalization (3NF)
 
## Tasks Performed

1. Customer Data Analysis

2. Product Category Analysis

3. Data Insertion, Updating and Deletion

4. SQL Constraints and Operators

5. Sales and Revenue Analysis

6. High-Value Customer Identification

7. Customer Ranking

8. Supplier Stock Analysis

9. Product Sales Ranking

10. Database Normalization

11. Prime Member Analysis

12. Business Insights Generation
 
## Key Insights

- Identified high-value customers.

- Analyzed top-selling products.

- Identified cities with more Prime members.

- Analyzed supplier-wise stock quantities.

- Identified customers without orders.
 
## Objective

To develop SQL skills and generate meaningful business insights through database analysis.
